# 한글 신규 기능 실사용 점검표

- 기준일: 2026-08-05
- 대상: 2026-08-04~05에 추가된 한글 작업 6종 + 어휘 통합
- 전제: 한글이 실행 중이고 편집 모드로 문서가 연결돼 있어야 한다
- 문장은 `engine/edit_mode/stage5.py`의 실제 인식 규칙에서 추출했다

## 0. 먼저 자동 점검

사람이 손대기 전에 26개 검사가 자동으로 돈다. 여기서 실패하면 아래는 볼 필요 없다.

```bash
python -m verification.hwp_table_probe
```

`"status": "passed"`가 나와야 한다. 끝나면 한글 프로세스가 남지 않는다.

## 1. 줄간격 — 6건

문단에 커서를 두고 말한다. 배수·퍼센트·이름 세 가지를 다 받는다.

| # | 문장 | 기대 |
|---|---|---|
| 1 | `줄간격 160으로 해줘` | 160% |
| 2 | `줄간격 1.5배로` | 150% |
| 3 | `행간격 200%` | 200% |
| 4 | `줄 간격 넓게` | 200% |
| 5 | `줄간격 좁게` | 130% |
| 6 | `줄간격 2배` | 200% (작은 맨숫자는 배수로 읽는다) |

**막혀야 하는 것**

| # | 문장 | 기대 |
|---|---|---|
| 7 | `줄간격 10` | 범위 밖 안내 (50~500%) |
| 8 | `줄간격 없애` | 값을 지정해달라는 안내 — **글이 지워지면 안 된다** |

## 4. 표 칸 입력 — 4건

표가 있는 상태에서, 넣을 내용을 **따옴표로 감싸** 말한다.

| # | 문장 | 기대 |
|---|---|---|
| 18 | `표 2행 3열에 "매출" 넣어줘` | 그 칸에만 입력 |
| 19 | `표 1행 1열에 "구분" 입력` | 같음 |
| 20 | `표 3행 4열에 "합계" 채워줘` | 같음 |
| 21 | 3×4 표에 `표 9행 1열에 "넘침" 넣어줘` | 표에 없는 행이라는 안내 |

**확인 포인트** — 18~20을 연달아 한 뒤 **다른 칸이 하나도 안 바뀌었는지** 본다.

## 7. 어휘 통합 — 7건

같은 뜻인데 경로에 따라 다르게 동작하던 것을 하나로 합쳤다. **이번 수정의 핵심이라 꼭 확인한다.**

### 7.1 정렬 (이전에 편집 모드에서 인식 안 되던 표현)

| # | 문장 | 기대 |
|---|---|---|
| 30 | `좌측 정렬해줘` | 왼쪽 정렬 |
| 31 | `우측으로 정렬` | 오른쪽 정렬 |
| 32 | `배분 정렬해줘` | 양쪽 정렬 |
| 33 | `중앙 정렬` | 가운데 정렬 |

### 7.2 확인 취소 (승인 대기 상태에서)

아무 편집이나 요청해서 **승인 대기 화면**을 띄운 뒤 하나씩 답해본다.

| # | 답변 | 기대 |
|---|---|---|
| 34 | `하지마` | 취소 |
| 35 | `아니오` | 취소 |
| 36 | `ㄴㄴ` | 취소 |

> 34~36은 전부 이전에 일부 확인창에서만 먹히던 표현이다. 특히 **PDF 외부 전송 확인**에서 확인해보면 좋다 — 문서 내용이 외부로 나가는 승인이라 취소가 확실히 먹혀야 한다.

## 8. 되돌리기 — 6종 전부

각 기능을 하나씩 실행한 뒤 **바로 실행 취소**한다.

| # | 대상 | 확인 |
|---|---|---|
| 37 | 줄간격 | 이전 줄간격으로 |
| 38 | 선택 삭제 | 지운 글이 그대로 |
| 39 | 표 삽입 | 표가 사라짐 |
| 40 | 표 칸 | 이전 칸 내용으로 |
| 41 | 글머리표 | 이전 상태로 |
| 42 | 쪽 나눔 | 쪽 수가 돌아옴 |

## 9. 미리보기가 문서를 안 건드리는지 — 6건

승인 화면이 떴을 때 **승인하지 말고 취소**한 뒤, 문서가 요청 전과 똑같은지 본다.

37~42의 각 기능에 대해 한 번씩. 특히 **표 칸 입력**은 한글이 칸을 읽으려면 커서를 옮겨야 하는데, 미리보기 후 **커서가 원래 자리로 돌아와 있어야 한다**.

## 지원하지 않는 것

- **여백·용지 방향**은 아직 안 된다. 쓰기는 되는데 되돌리기를 설명하지 못해 넣지 않았다. 사유는 `KNOWN_LIMITATIONS.md` 참조. 한글에서 직접 설정한다.
- 표 삭제, 행·열 추가, 셀 병합은 이번 범위가 아니다.

---

## 안 되는 걸 발견하면

계획서 기준으로 **그게 다음 우선순위를 정하는 데이터**다. 기록할 것:

1. 말한 문장 그대로
2. 기대한 결과 / 실제 결과
3. 미리보기에 뭐라고 떴는지 (또는 안 떴는지)

특히 **미리보기가 엉뚱한 걸 보여준 경우**가 가장 값어치 있다 — 26번 버그가 정확히 그 유형이었다.
