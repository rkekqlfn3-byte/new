# JARVIS Goal Phase 3 구현·검증 보고서

작성일: 2026-07-23

범위: 검증된 1단계 Undo의 GUI 연결·만료·재검증

## 결과

기존 4개 Office 편집 어댑터의 구조화된 Undo를 작업 상태 카드에서 한 번 사용할
수 있게 연결했다. 버튼은 결과 검증과 Undo 문맥 계약이 모두 충족될 때만 보인다.

## 실행 전 재검사

1. 현재 편집 세션 ID.
2. 검증된 직전 작업 ID.
3. 문서 fingerprint.
4. 현재 선택·커서 context fingerprint.
5. Undo 기록 생성 후 5분 이내인지.
6. Undo 기록이 아직 소비되지 않았는지.

하나라도 다르면 문서를 변경하지 않는다. Undo 성공 후에는 기존 구현대로 원래
값·서식·선택의 구조화 스냅샷을 다시 읽고, 기록을 제거해 중복 사용을 막는다.

## 개인정보 경계

GUI 토큰에는 형식 검사를 통과한 불투명 식별자와 해시 지문만 포함한다. 전체
경로, 문서명, 선택 텍스트, 원래 값·서식은 사용자 이벤트에 포함하지 않는다.

## 검증

- 전체 회귀: 976건 실행, 973건 통과, 외부 AI 3건 skip, 실패·오류 0.
- 검증되지 않았거나 토큰이 불완전한 결과에서 버튼 미노출.
- 이전 작업 ID 버튼 차단 및 Undo 기록 보존.
- 5분 만료 차단.
- 선택 변경 뒤 기존 Undo 폐기.
- 검증 성공 Undo 후 기록 제거와 중복 사용 차단.
- JavaScript 문법과 `textContent` 기반 버튼 렌더링 계약 통과.

실제 화면의 크기·포커스·화면 읽기 동작은 Phase 7 수동 수용 배터리에서 최종
확인한다.
