# JARVIS Prototype 1.0 직접 시험 문장 100개

이 문서는 로컬 테스트용 EXE에서 일반 명령, 네 Office 앱 편집, 연속 수정,
VBA, 문서 워크플로, 명시적 선호 학습과 자가 진단을 한 번씩 확인하기 위한
수동 인수 테스트 목록이다.

## 시작 전 준비

- 실제 업무 원본 대신 복사본을 사용한다.
- 편집 시험은 EXE의 편집 화면에서 파일을 연결하고, 문서가 저장된 상태인지 확인한다.
- 쓰기 명령은 미리보기의 대상과 변경 전·후를 확인한 뒤 `적용`한다. 취소 시험은
  반드시 `취소`를 누른다.
- Excel은 표 머리글 `상태`, `매출`과 몇 줄의 예제 값을 준비한다.
- 한글과 Word는 세 문장 이상의 예제 본문과 표 하나를 준비한다.
- PowerPoint는 제목/본문 Shape가 있는 두 장 이상의 슬라이드를 준비한다.
- VBA 시험은 복사한 `.xlsm`에서 실제 모듈명과 매크로명으로 문장을 바꿔 사용한다.
- `[선택 변경 차단]` 시험에서는 미리보기 이후 Office에서 선택을 바꾼 다음
  `적용`한다. 문서가 바뀌지 않고 새 요청을 요구하면 통과다.

97. `PPT는 항상 7장으로 만들어줘` — 세 번째 증거에서 활성화 승인 카드가 나오며, 승인 후에만 기본값이 저장되면 통과.
98. `이 엑셀을 분석해서 보고서와 PPT 만들어줘` — 장수를 직접 지정하지 않았을 때 승인된 기본값대로 정확히 7장이 생성되면 통과.
99. `PPT 기본 장수 선호 취소` — 해제 승인 후 다음 무지정 워크플로가 기본 5장으로 돌아오면 통과.

## 10. 자가 진단

100. `최근 오류 진단해줘` — 앞선 차단·실패가 있으면 원문, 절대 경로, 문서 내용 없이 실패 단계·원인 후보·필요 테스트만 표시되고 자동 수정이나 새 EXE 빌드를 하지 않으면 통과.
