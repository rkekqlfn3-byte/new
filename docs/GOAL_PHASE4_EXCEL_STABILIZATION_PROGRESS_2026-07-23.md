# JARVIS Goal Phase 4 Excel 안정화 중간 보고서

작성일: 2026-07-23

상태: A군 자동 검증 완료, 수동 100문장 수용 확인 대기

## 완료한 범위

- 값·수식 입력.
- 합계·평균 수식 및 고정값.
- 굵기·해제, 글자 크기, 정렬, 배경색, 글자색.
- 필터·해제, 표 전체 행 정렬, 범위·현재 시트 치환.
- 행·열 삽입, 선택 읽기.
- Excel VBA와 관계·조인·보고서·PPT 워크플로의 기존 검증 경계 유지.
- 작업별 자연어 상태 설명과 실패 분류 연결.
- 가능한 8개 작업의 구조화 Undo 목록 고정.

## 이번 점검에서 수정한 결함

1. `굵게 해제`를 굵게 적용으로 해석하던 반대 동작.
2. live probe의 prepare 후 장기 COM proxy가 끊겨 execute가 실패하던 수명 문제.
3. 핵심 probe가 실행 중인 사용자 Excel에 붙을 수 있던 격리 위반.
4. 실패한 핵심 probe가 종료 코드 0을 반환하던 판정 문제.
5. 보조 probe 보고서에 임시 셀 내용과 전체 행이 남던 불필요한 내용 기록.

## 자동 검증 증거

- 전체 회귀: 983건 실행, 980건 통과, 외부 AI 3건 skip, 실패·오류 0.
- 핵심 Excel probe: 별도 PID, 사용자 인스턴스 비접촉, 합계 수식·고정값,
  조건부/직접 서식, 문맥 변경 차단, 소유 프로세스 종료 통과.
- 보조 Excel probe: 별도 PID, 범위 서식, 필터·해제, 치환, 전체 행 정렬,
  소유 프로세스 종료 통과.
- probe 영구 결과는 셀 값·경로·문서 내용을 기록하지 않는다.

## 남은 Phase 4 게이트

- 기존 100문장 수동 시험에서 중대 오대상·무승인 쓰기 0건 확인.
- VBA와 복합 워크플로의 최신 격리 probe 증거를 Phase 6에서 재확인.
- B군 4종은 선택 범위다. A군·1,000문장·수동 수용을 늦추지 않도록 현재는
  이월 후보로 유지한다.
