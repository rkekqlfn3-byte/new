# JARVIS PDF-4 분할·병합·회전 완료 보고서

- 기준일: 2026-08-04 KST
- 작업 브랜치: `codex/pdf-capabilities`
- 범위: Python 소스와 Eel 명령·승인 흐름
- EXE 빌드: 수행하지 않음

## 1. 판정

PDF-4의 필수 범위인 선택 페이지 추출, 여러 PDF 병합, 지정 페이지 회전, 승인 후 원자적
출력, 재열기 검증, 실패 정리와 제한된 Undo를 구현했다.

여기서 “분할”은 선택한 페이지를 순서대로 모아 새 PDF 한 개를 만드는 기능이다. 회전은
원문 전체를 새 PDF로 복사하면서 지정한 페이지만 상대 회전한다. 병합은 현재 연결 PDF를
첫 번째로 두고, 네이티브 파일 선택창에서 고른 추가 PDF를 승인 카드에 표시된 순서대로
이어 붙인다.

## 2. 안전 계약

- 모든 작업은 원본이 아닌 새 형제 PDF를 만든다.
- 승인 카드가 나오기 전에는 출력 파일을 만들지 않는다.
- 승인 대기 중 연결 PDF, 추가 원본, 출력 이름이 바뀌면 실행하지 않는다.
- 원본과 같은 경로, 네트워크 경로, 심볼릭 링크, 이미 존재하는 출력은 차단한다.
- 페이지 범위는 오름차순·중복 제거 정책을 사용하며 문서 범위를 벗어나면 준비 단계에서 막는다.
- 병합 입력 전체가 100MB 또는 결과 2,000페이지 안전 한도를 넘으면 쓰기 전에 막는다.
- 같은 디렉터리의 임시 PDF에 쓴 뒤 재열기 검증을 통과한 경우에만 `os.replace`로 확정한다.
- 실패 시 임시 파일을 제거하고, 최종 이동 뒤 검증 실패도 방금 쓴 fingerprint가 그대로일
  때만 결과를 삭제한다.
- 내부 pypdf·파일 시스템 예외의 원문과 경로는 사용자 오류 메시지로 내보내지 않는다.

## 3. 재열기 검증

새 PDF는 다음을 모두 다시 읽어 확인한다.

- `%PDF-` 헤더
- 예상 페이지 수
- 원본 페이지 텍스트 fingerprint 순서
- 각 페이지 회전값
- 모든 원본 파일 fingerprint 불변

텍스트가 없는 페이지도 빈 텍스트 fingerprint와 회전값으로 순서를 검증한다. 출력 검증은
기존 PDF 읽기 제한을 그대로 사용하므로 손상·암호화·초대형 결과를 성공으로 오판하지 않는다.

## 4. 승인과 Undo

승인 카드에는 입력 파일 이름과 순서, 출력 파일 이름, 결과 페이지 수, 분할 대상 페이지 또는
회전 대상·방향을 표시한다. 실제 절대 경로와 본문은 공개 확인 데이터에서 제외한다.

Undo는 현재 프로세스에서 가장 최근에 성공한 PDF 결과물 하나만 대상으로 한다. 별도 삭제
승인을 다시 받고, 생성 직후 기록한 SHA-256과 현재 파일이 완전히 같을 때만 삭제한다. 사용자가
결과를 수정했거나 JARVIS가 재시작된 경우에는 삭제하지 않는다.

## 5. 자동·실제 검증 결과

| 검증 | 결과 |
|---|---:|
| PDF-4 intent·서비스·실패 주입 단위 테스트 | 통과 |
| prepare → 승인 → execute 통합 테스트 | 통과 |
| 전체 중앙 회귀 | 1,204개 통과, 조건부 3개 제외 |
| 함수 99줄 유지보수 예산 | 통과 |
| owned-fixture PDF-4 probe | 통과 |
| Poppler 전체 페이지 렌더링 | 통과 |

owned-fixture probe는 3페이지 PDF와 2페이지 PDF만 사용했다. 2~3페이지 추출, 지정 페이지
회전, 3+2페이지 병합, 변경 없는 결과 Undo를 실행했고 원본 불변과 임시 파일 부재를 확인했다.
분할 2페이지, 병합 5페이지, 회전 3페이지를 모두 PNG로 렌더링했다. 대표 페이지를 직접
확인한 결과 텍스트 누락·겹침·잘림이 없었고 회전 대상만 의도한 방향으로 표시됐다.

## 6. 남은 범위

- PDF-7: PDF 전용 대규모 문장, 실패 주입, 성능, 개인정보, Goal gate 편입
- 선택 PDF-5: OCR provider와 환경 capability
- 선택 PDF-6: Edge·Acrobat의 증명 가능한 현재 페이지·선택 영역 연결
- 사용자 수동 확인: 실제 보유 PDF의 승인 카드 이해도와 병합 순서 확인

PDF-4는 원본 위 직접 편집, 기존 출력 덮어쓰기, 암호·DRM 우회, 전자서명을 지원하지 않는다.
이 제한은 안전 계약이며 자동으로 우회하지 않는다.
